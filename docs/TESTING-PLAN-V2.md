## Rules carried from v1

- Strict opt-in envs: every nightly-sized variant (`SE2M*_NIGHTLY`) panics on any value other than documented ones.
- Evidence preservation: test name, build mode, dataset, environment, results, PASS/FAIL, known limitations — in the artifact, per suite.
- Correctness pins are asserts; performance numbers are report cells. A perf number never gates a test.
- Report writers regenerate their artifact only when run with the env set; never re-run a smoke after a nightly (artifact churn, M7 lesson).
- RSS measurement is Windows-only (PowerShell WorkingSet64 child sampler); non-Windows rows = honest NOT_SAMPLED cells.
- Child-kill recovery tests spawn `current_exe --exact <test>` with env gates (no args = the whole suite — KSE-15 lesson).
